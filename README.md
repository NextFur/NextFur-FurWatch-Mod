> Este repositório compreende apenas o Mod do FurSMP o FurWatch;

> O sistema contempla capacidades para executar em desenvolvimento e teste o Mod do FurSMP

## 🔧 Funcionalidades:
### ✨ Mod
* Login e Autenticação - API da NextFUR ✅
* Whitelisting com a API da NextFUR ✅
* Verificação de Token com API e conexão com o Lyra Launcher ✅
* Import de Blocos e CommonUse features para o FurSMP ✅
* Comandos:
  * /roll - Role um dado de RPG ✅
  * /tmenu - Menu de title ✅
  * /skycolor - Menu para trocar a cor do céu ✅
  * /economy - Comandos administrativos do controle de economia ✅
  * /tell - Comando de mensagem atrelado ao PDA ⭕
  * /pickpoket - Comando para tentar a sorte em roubar a carteira de algum jogador que esteja proximo ⭕
* Efeitos customizados: 
  * MoonGravity ✅
  * PowerDown ✅
  * BigSize ✅
  * SmallSize ✅
  * EMP ✅
* Sistema de Economia completo com carteira e dinheiro fisico ✅
  * Dinheiro Físico ✅
  * Carteira com armazém de dinheiro ✅
  * Comandos de economia ✅
  * Dinheiro estacável ✅
  * Dinheiro virtual no PDA ⭕
  * ATM de dinheiro do banco shield para depositar no PDA ⭕
* PDA:
  * Mensagens ✅
  * Menu do tablet ✅
  * Bloco de notas ✅
  * Fragmentos do mapa ⭕
  * Shield Bank APP ⭕
* Computador e model de PC ✅
  * Para rodar algum site que configurado (precisa estar no criativo para abrir o menu de admin) ✅
  * Quando acessado, abrir o site na GUI; ✅
