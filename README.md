> Este repositório compreende apenas o Mod do FurSMP o FurWatch;

> O sistema contempla capacidades para executar em desenvolvimento e teste o Mod do FurSMP

## 🔧 Funcionalidades:
### ✨ Mod
* Login e Autenticação ✅
* Whitelisting ✅
* Verificação de Token com API ✅
* Import de Blocos e CommonUse features para o FurSMP ✅
* Adição de comando /offrp ✅
* Adição da Lanterna pressionando "F" ✅
* Adição de comandos e interações dentro do mod do fursmp ✅
* Adição do comando /skycolor ✅

## Dependencias de Terceiros
* O mod inclui o Veil empacotado via `jarJar` no artefato final (`META-INF/jarjar`).
* Licenca do Veil: GNU (consulte o repositorio oficial do Veil para os termos e a versao exata da licenca).
